**Goal:** Print from LisaWrite through the OS's own ImageWriter driver, out an emulated Z8530 Serial B, into an escape-code interpreter, and onto the user's real printer via the standard macOS print panel.

**Architecture:** Investigation-led as established. One evidence task (chase RSBASE + derive the OS serial driver's exact register contract — the SCC base has NEVER been chased; hardware-notes flags it), one device task (SCC8530 transmit path + PrinterPort seam, TDD from the derived contract), one pure-logic task (ImageWriterInterpreter, golden-tested, no Apple data), one integration task (job spooler + LisaApp print panel + lisadbg capture + the live Preferences-configured print), then close. The PM-persistence open question is answered by evidence in Task 1 and either lands in Task 4 (if cheap) or is documented-deferred.

**Tech Stack:** existing. Primary sources: the OS serial-driver units (start from hardware-notes:875 "Level 6: RS-232 SCC (mover:822-849, INITRAP:136-137)" and :1655 "RSBASE not chased — consult SOURCE-SERCARD/SOURCE-DEVCONTROL"), `LIBS/LIBPR/LibPr-ciprint` (the ImageWriter/C.Itoh driver — the escape-code contract), SOURCE-CD/Preferences flows for the Serial-B printer attach, ImageWriter/C.Itoh 8510 references (bitsavers manuals) as cross-check only — the OS source is the contract.
